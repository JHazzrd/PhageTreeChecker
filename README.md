A repo containing my Bioinformatics Masters project: A script for checking phage phylogenetic trees. To fully use the script, representative phage genomes must be gotten: These should be accessible by running representative_phage_get.py, then representative_phage_genomes_get.py, then finally rep_phage_outliers_get.py. The resulting FASTA file is 220mb, and thus is not on this repo
